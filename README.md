# TankLapse

> ⚠️ **Project Under Active Development**
> **TankLapse** is currently in early-stage construction and is not yet ready for production use. Features and builds are subject to rapid change.

---

## 📌 Overview

**TankLapse** is a lightweight interval screenshot capture and timelapse utility.

It writes individual frames directly to local disk storage as lightweight image files to prevent RAM overload during infinite-duration recordings, automatically stitching them into high-framerate MP4 timelapse videos upon completion.

---

## 🛠️ Status & Roadmap

* [ ] Core screenshot capture engine (interval timer & screen hooks)
* [ ] Direct-to-disk frame stream (JPEG/PNG buffer management)
* [ ] Batch video stitching pipeline (FFmpeg / native encoder integration)
* [ ] Auto-cleanup routine for temporary frame storage
* [ ] Desktop UI / System Tray interface
